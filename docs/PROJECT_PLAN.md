# MCP KPI PoC 기획서

## 1. 프로젝트 개요

- 프로젝트명: MCP 기반 KPI 조회·분석 PoC
- 목적: AI 클라이언트가 MCP를 통해 KPI 데이터를 조회하고, 달성률을 계산하며, 미달 항목을 요약할 수 있는지 검증한다.
- 구현 수준: 실제 서비스가 아닌 도입 가능성 검증용 PoC

## 2. 성공 기준

다음 조건을 모두 충족하면 PoC를 완료한 것으로 판단한다.

- MCP 서버 1개가 로컬 환경에서 실행된다.
- 서로 연관된 MCP Tool 3개가 동작한다.
- 로컬 JSON 또는 CSV 데이터 소스 1개와 연동된다.
- AI 클라이언트에서 자연어 요청으로 각 Tool을 호출할 수 있다.
- 정상 및 오류 시나리오를 포함한 테스트 10건 중 9건 이상 성공한다.
- 다른 사용자가 README만 보고 설치와 실행을 재현할 수 있다.
- 실행 결과, 제약사항 및 후속 개발 항목이 문서화된다.

## 3. 구현 범위

### 포함 범위

1. `list_kpis`
   - 전체 KPI 목록과 현재 실적을 조회한다.

2. `calculate_achievement`
   - 선택한 KPI의 목표값 대비 실적 달성률을 계산한다.

3. `summarize_kpis`
   - 전체 KPI의 달성 상태와 미달 항목을 요약한다.

4. 입력값 검증 및 기본 오류 처리
   - 존재하지 않는 KPI
   - 숫자가 아닌 목표값 또는 실적값
   - 비어 있거나 손상된 데이터

### 제외 범위

- 운영 환경 배포
- 사내 데이터베이스 직접 연결
- 외부 서비스 OAuth 및 사용자 인증
- 관리자 화면 또는 별도 웹 UI
- 실시간 데이터 동기화
- 세밀한 권한 관리와 감사 로그

## 4. 예시 데이터 구조

```json
{
  "id": "monthly-revenue",
  "name": "월 매출",
  "target": 100000000,
  "actual": 85000000,
  "unit": "원"
}
```

달성률은 `(actual / target) * 100`으로 계산한다. 목표값이 0 이하인 경우 계산 오류로 처리한다.

## 5. 기술 방향

- 언어: TypeScript
- 통신 방식: MCP stdio transport
- 데이터 소스: 로컬 JSON 우선
- 테스트: Tool 단위 테스트와 MCP 호출 시나리오 테스트
- 클라이언트: MCP Tool 호출을 지원하는 AI 클라이언트

외부 인증이나 네트워크 상태 때문에 일정이 지연되지 않도록, PoC에서는 로컬 데이터를 사용한다. 데이터 접근 계층을 분리하여 후속 단계에서 API나 데이터베이스로 교체할 수 있게 한다.

## 6. 테스트 시나리오

최소 다음 항목을 검증한다.

1. 전체 KPI 목록 조회
2. KPI가 없는 빈 데이터 조회
3. 특정 KPI 달성률 계산
4. 목표를 초과한 KPI 계산
5. 목표에 미달한 KPI 계산
6. 존재하지 않는 KPI 요청
7. 목표값이 0인 KPI 처리
8. 잘못된 숫자 형식 처리
9. 전체 KPI 요약
10. 손상된 데이터 파일 처리

## 7. 산출물

- 실행 가능한 MCP 서버 소스 코드
- 예제 KPI 데이터
- 자동화된 테스트 및 결과
- 설치·실행·클라이언트 연결 방법이 포함된 README
- PoC 결과와 한계, 후속 개발 제안

## 8. 완료 후 판단

PoC 결과를 기준으로 다음 단계 진행 여부를 결정한다.

- Go: 성공 기준을 충족하고 실제 업무 데이터 연결 가치가 확인됨
- Conditional Go: 기능은 검증됐으나 보안 또는 데이터 연동 검토가 추가로 필요함
- No-Go: MCP 적용 효과가 기존 방식보다 낮거나 핵심 시나리오 구현이 불가능함
